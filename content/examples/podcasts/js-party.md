# JS Party

A community celebration of JavaScript and the web.

JS Party is a weekly celebration of JavaScript and the web. This show records LIVE on Thursdays at 1pm US/Eastern. Panelists include Jerod Santo, Nick Nisi, Amelia Wattenberger, Kevin Ball, Divya, Feross Aboukhadijeh, and Amal Hussein.

Topics discussed include the web platform (Chrome, Safari, Edge, Firefox, Brave, etc.), front-end frameworks (React, Svelte, Angular, Vue, etc.), Node.js, web animation, SVG, robotics, IoT, and much more.
